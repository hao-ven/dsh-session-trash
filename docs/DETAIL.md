# 会话回收站

DSH 只给归档、不给删除。这个插件补一个**可恢复**的删除：会话先搬进本地回收站，只有显式「彻底删除」才释放空间。

## 删除时到底做了什么

1. **拒绝错目标**：不能删正在跑这次调用的那个会话；运行中的会话默认拒绝（可选"停止并移入"）。
2. **释放内存里的 Agent**：DSH 把打开过的会话的 Agent 留在 Host 进程里，而 `dispose()` 只属于它的所有者。本插件在 `ctx.agents.create/resume` 上包了一层，把返回的句柄按会话 id 记下来，删除时调用 `handle.dispose()` —— 所以那一行会立刻从所有界面消失，不再留"删了还在未分组里"的鬼影。
3. **先改账本**：从工作区账户摘掉，清归档集合与置顶集合。
4. **整目录 rename**：`sessions/<桶>/<id>` → `$DSH_HOME/session-trash/<id>`。同卷原子，不复制字节；跨卷会明确报错。
5. **寄存派生数据**：把投影缓存行搬进回收站目录（`.projcache.json`），空掉的会话桶目录顺手移除；恢复时再搬回去，标题也从它读。

## 回收站

- 位置：`$DSH_HOME/session-trash/`，清单是同目录下的 `index.json`
- **永不自动过期**：清空间必须显式「彻底删除」
- 恢复：搬回原来的会话桶，并尝试挂回原工作区；工作区不在了就归「未分组」

## 入口

**回收站面板** —— 左侧栏多一个回收站图标（`本地回收站`）。点开是主面板，顶部分「回收站 / 归档」两段，左边按项目分组的会话列表，右边是选中会话的详情（宽窗口分栏，窄窗口退回行内展开）。

每行两个图标动作：

- **恢复**（↺）—— 搬回原会话桶并挂回原工作区；工作区不在了就归「未分组」
- **彻底删除**（🗑）—— 二次确认后真正释放空间

归档段则是「取消归档」和「移入回收站」。顶部还有搜索框（标题 / id / 目录）、按时间或大小排序、以及「清空回收站…」。

**工具** —— `trash_session` / `restore_session` / `purge_session` / `list_session_trash`，另有维护用的 `purge_orphan_caches`。

## 测试

`test/trash.test.mjs` 在临时 `DSH_HOME` 上跑完整链路（移入 → 列表 → 目录消失自愈 → 恢复 → 彻底删除），用插件注册的工具定义驱动，不需要真实宿主：

```powershell
$env:ELECTRON_RUN_AS_NODE=1
& "D:\DevTools\DeepSeek Harness\DeepSeek Harness.exe" "<插件目录>\test\trash.test.mjs"
```

## 限制

- 没有批量选择和拖拽；一次一条。
- 子代理子会话不跟着搬：删除父会话时只扫描并**警告**还留在磁盘上的子会话，不级联。
- 不清理附件对象：`.dsh/attachments/` 里的图片不随会话删除而回收。
- 依赖 `$DSH_HOME/sessions`、`storages/session_projcache` 的默认 JSONL 布局，按 DSH 0.2.2-rc.5 编写。
- Agent 句柄捕获只在插件加载**之后**创建的 Agent 上生效；插件加载前就打开的会话拿不到句柄（那种情况会给出警告，重启宿主即可）。
